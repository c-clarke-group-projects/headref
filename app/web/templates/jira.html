How to configure Jira

  1. 1Create a read only API tokenIn your Atlassian account settings, under Security, create an API token.
  2. 2Set the environmentSet JIRA_BASE_URL, JIRA_EMAIL, JIRA_API_TOKEN and optionally JIRA_PROJECT_KEYS in .env. See .env.example.
  3. 3Restart and syncRestart Headref, then press Sync Jira now or wait for the scheduled sync.
